# service-hello-world-6

A Spring Boot service that creates greetings for submitted names and lists the greetings it has stored.

Try this:

```bash
mvn spring-boot:run
curl -X POST http://localhost:8080/greeting -H 'Content-Type: application/json' -d '{"name":"Alice"}'
curl 'http://localhost:8080/greetings?page=0&size=20'
```

The service stores every greeting in the `GREETINGS` table and returns stored greetings newest first.

---

## Run and test

| Task | Command |
| --- | --- |
| Run the service | `mvn spring-boot:run` |
| Run all tests | `mvn test` |
| Build the jar | `mvn package` |

The service listens on port `8080` and uses an in-memory H2 database that Liquibase migrates at startup.

## API contract

The API is JSON only. Both endpoints accept and produce `application/json`.

### Create a greeting

`POST /greeting`

Request body:

```json
{
  "name": "Alice"
}
```

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | string | Yes | Must not be blank. A blank or missing name returns `400 Bad Request`. |

Response body (`201 Created`):

```json
{
  "id": "3f1c2e5a-9b1a-4f7d-8a2e-1c0d5b6f7a8b",
  "name": "Alice",
  "date": "2024-01-01T12:00:00Z",
  "response": "Hello, Alice!"
}
```

| Field | Type | Notes |
| --- | --- | --- |
| `id` | UUID string | Generated by the service for each greeting. |
| `name` | string | Echoes the submitted name. |
| `date` | ISO-8601 instant (UTC) | Creation timestamp. Jackson serializes instants as ISO-8601 strings, not epoch numbers. |
| `response` | string | The generated greeting text. |

The service persists the same four values to `GREETINGS` (`ID`, `NAME`, `DATE`, `RESPONSE`).

### List greetings

`GET /greetings`

| Parameter | Type | Default | Notes |
| --- | --- | --- | --- |
| `page` | integer | `0` | Zero-based page index. |
| `size` | integer | `20` | Rows per page. The configured maximum is `100`. |

Sorting is fixed: results are always ordered by `date` descending (newest first). A client-supplied `sort` parameter is ignored.

Response body (`200 OK`):

```json
{
  "content": [
    {
      "id": "3f1c2e5a-9b1a-4f7d-8a2e-1c0d5b6f7a8b",
      "name": "Alice",
      "date": "2024-01-01T12:00:00Z",
      "response": "Hello, Alice!"
    }
  ],
  "page": {
    "size": 20,
    "number": 0,
    "totalElements": 1,
    "totalPages": 1
  }
}
```

The page envelope uses the Spring Data `PageSerializationMode.VIA_DTO` format, which is configured in `WebConfig`.

## Default assumptions

These defaults are not part of the ticket wording, so they are recorded here and mirrored in code constants:

- **Greeting template:** `Hello, %s!`, defined by `GreetingServiceImpl.GREETING_TEMPLATE`. A request for `Alice` produces `Hello, Alice!`.
- **Default page size:** `20`, defined by `GreetingController.DEFAULT_PAGE_SIZE` and `spring.data.web.pageable.default-page-size`.
- **Maximum page size:** `100`, from `spring.data.web.pageable.max-page-size`. Larger requested sizes are capped.
- **Timestamps:** generated in UTC from an injectable `java.time.Clock` bean, so tests can freeze time.
- **Identifiers:** random version 4 UUIDs generated by the service rather than the database.
- **Create status code:** `201 Created` for a successful `POST /greeting`.

## Code structure

- `controller/GreetingController` — Spring MVC `@RestController` exposing both endpoints.
- `dto/GreetingRequest`, `dto/GreetingResponse` — Java records for the request and response payloads.
- `service/GreetingService` and `service/impl/GreetingServiceImpl` — business logic, wired with Lombok `@RequiredArgsConstructor`.
- `entity/Greeting` — JPA entity for the `GREETINGS` table, using Lombok accessors and a builder.
- `repository/GreetingRepository` — Spring Data JPA repository.

## Tests

- `GreetingControllerTest` — MockMvc happy-path coverage for the create and list contracts, including pagination and ordering.
- `GreetingServiceImplTest` — JUnit 5 and Mockito coverage for greeting generation and sorted paging.
- `GreetingRepositoryTest` — persistence coverage for the `GREETINGS` columns and sorted paging.
